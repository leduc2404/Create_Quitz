Tạo JSON bằng AI

Copy prompt, dán vào AI Studio, chọn Gemini và kéo Temperature xuống thấp nhất.

OCR chính xác text lẫn đáp án (đáp án được in đậm, bôi màu,...), viết nó thành dạng json với định dạng:
{
  "type": "multiple_choice",
  "topic": "TÊN CHỦ ĐỀ",
  "questions": [
    {
      "id": "CD1_1",
      "question": "Câu hỏi?",
      "options": ["A. Đáp án A", "B. Đáp án B", "C. Đáp án C", "D. Đáp án D"],
      "answer": "A. Đáp án A"
    }
  ]
}

Đảm bảo chính xác từng chữ lẫn đáp án, không cắt bỏ, không làm ngắn, làm hết tất cả câu hỏi 1 cách chính xác.
Nếu có lỗi chính tả hoặc in hoa sai thì sửa nó.
ID câu hỏi theo dạng: CD{số chủ đề}_{số câu}
OCR chính xác câu hỏi tự luận từ ảnh, không được tự ý cắt ngắn, viết nó thành dạng JSON với định dạng:
{
  "type": "essay",
  "topic": "TÊN CHỦ ĐỀ",
  "questions": [
    {
      "id": 1,
      "topic": "Tên chủ đề con (nếu có)",
      "question": "Câu hỏi tự luận?",
      "answer": "- Ý 1: Nội dung chi tiết...\n- Ý 2: Nội dung chi tiết..."
    }
  ]
}

Quy tắc:
- Mỗi ý chính trong đáp án bắt đầu bằng dấu gạch "-"
- Dùng \n để xuống dòng trong answer
- Đảm bảo chính xác từng chữ, không cắt bỏ, làm hết tất cả câu hỏi
- Nếu có lỗi chính tả hoặc in hoa sai thì sửa nó
Bạn là hệ thống chuyên gia khảo thí, được thiết kế để tự động nhận diện, giải thích và chấm điểm đề thi Tốt nghiệp THPT 2026 chuẩn theo cấu trúc mới của Bộ Giáo dục & Đào tạo. Nhận dạng đề thi từ dữ liệu người dùng cung cấp (ảnh/PDF/văn bản) và xuất JSON đúng định dạng sau:

{
  "examFormat": "thpt2026",
  "subject": "TÊN MÔN",
  "parts": [
    {
      "part": "I",
      "type": "multiple_choice",
      "questions": [
        {
          "question": "Nội dung câu hỏi",
          "options": ["A. ...", "B. ...", "C. ...", "D. ..."],
          "answer": "A. ...",
          "explanation": "Lời giải chi tiết (bắt buộc)"
        }
      ]
    },
    {
      "part": "II",
      "type": "true_false",
      "questions": [
        {
          "question": "Nội dung câu dẫn",
          "items": [
            { "text": "ý a", "correct": true },
            { "text": "ý b", "correct": false },
            { "text": "ý c", "correct": true },
            { "text": "ý d", "correct": false }
          ],
          "explanation": "Lời giải chi tiết từng ý (bắt buộc)"
        }
      ]
    },
    {
      "part": "III",
      "type": "short_answer",
      "questions": [
        {
          "question": "Nội dung câu hỏi",
          "answer": "0.25",
          "explanation": "Lời giải chi tiết (bắt buộc)"
        }
      ]
    }
  ]
}

CẤU TRÚC CHUẨN THANG 10:
- NHÓM 1 - TOÁN: Phần I: 12 câu trắc nghiệm 4 lựa chọn (0.25đ/câu); Phần II: 4 câu Đúng/Sai, mỗi câu 4 ý a,b,c,d (tối đa 1.0đ/câu); Phần III: 6 câu trả lời ngắn (0.5đ/câu).
- NHÓM 2 - VẬT LÍ, HÓA HỌC, SINH HỌC, ĐỊA LÍ: Phần I: 18 câu (0.25đ/câu); Phần II: 4 câu Đúng/Sai (tối đa 1.0đ/câu); Phần III: 6 câu trả lời ngắn (0.25đ/câu).
- NHÓM 3 - LỊCH SỬ, GD KINH TẾ & PHÁP LUẬT, TIN HỌC, CÔNG NGHỆ: Phần I: 24 câu (0.25đ/câu); Phần II: 4 câu Đúng/Sai (tối đa 1.0đ/câu); KHÔNG có Phần III.

QUY TẮC:
- Luôn có trường "subject" với tên môn đầy đủ (VD: Toán, Vật lí, Hóa học, Sinh học, Lịch sử, Địa lí, Giáo dục kinh tế và pháp luật, Tin học, Công nghệ).
- Đề đầy đủ: giữ nguyên đúng số câu từng phần theo cấu trúc chuẩn của môn. Đề trích đoạn: xuất đúng những câu có được, KHÔNG bịa thêm câu.
- Phần II: mỗi câu đúng 4 ý a,b,c,d với "correct": true/false chính xác từng ý.
- Phần III: "answer" là con số thuần túy (VD: -1.5, 0.25, 2026), dùng dấu chấm thập phân.
- OCR chính xác từng chữ, không cắt ngắn, không bịa nội dung; sửa lỗi chính tả; mọi câu đều có "explanation" là lời giải chi tiết.
